# 권현민

프로덕트 디자이너입니다. 규칙과 예외가 많은 B2B 제품에서 문제를 정의하고, 사람들이 실제로 쓰는 화면으로 만듭니다.

지금은 세일즈맵에서 AI CRM을 만들고 있습니다. 그 전에는 티맥스가이아에서 공공기관과 기업이 쓰는 문서 편집 SaaS를, 에이아이콴텍에서 로보어드바이저 서비스를 만들었습니다.

AI 기능은 잘 대답하게 만드는 문제이기 전에, 무엇에 대해 대답할 수 있는지를 정하는 문제라고 생각합니다. 그래서 처음에는 진행 중인 거래에 대해서만 대화할 수 있게 좁혀 베타로 냈습니다. 이후 인터뷰와 실제 대화 기록에서 사용자가 AI에게 원한 것이 흩어진 기록의 요약과 다음에 할 일 제안이라는 것을 확인하고, 대화 범위를 잠재 고객·회사·고객까지 넓혔습니다.

문제가 반복되면 화면부터 고치지 않습니다. 고객사마다 워크스페이스가 중복 생성되던 문제는 세팅을 돕다 발견해, 원인이 초대 동선을 인지하지 못하는 데 있다는 것을 확인하고 가입 단계까지 거슬러 올라가 고쳤습니다. 중복 21% → 4.4%.

## 최근에 한 일

**AI 어시스턴트 대화 범위와 진입 지점 재설계.** 고객과 거래 정보가 있는 화면에서 AI를 열었을 때 다시 찾는 비율이 높다는 것을 확인하고, AI를 호출하는 위치를 그 맥락으로 옮겼습니다. 인터뷰 40건과 대화 기록 1,500건으로 니즈를 검증해 대화 범위도 함께 넓혔습니다. 사용량 8.5% → 17.2%, 102.4% 증가.

**AI 미팅 녹음.** POC부터 출시, 출시 후 개선까지 맡았습니다. 메뉴 안에 숨어 있던 노트 저장과 템플릿 기능을 화면 위로 꺼냈습니다. 노트 저장률 7.9% → 27.8%, 첫 사용 후 이탈률 47.7% → 38.7%.

**삭제 정책 리뉴얼.** 데이터 중요도에 따라 삭제 절차의 난이도를 다르게 설계해, 삭제 실수와 번거로운 절차라는 상반된 불만을 같이 해결했습니다. 복구 요청 12건 → 1건.

**투자 성향 분석 퍼널.** 성향 분석 문항과 홈 화면의 우선순위를 다시 잡았습니다. 성향 분석 전환율 +41.2%p, 가입까지 걸리는 시간 50% 단축.
