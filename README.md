# 권현민

프로덕트 디자이너입니다. 규칙과 예외가 많은 B2B 제품에서, 사람들이 왜 그 기능을 안 쓰는지 알아내는 일을 합니다.

지금은 세일즈맵에서 AI CRM을 만듭니다. 그 전에는 티맥스가이아에서 공공기관과 기업이 쓰는 문서 편집 SaaS를, 에이아이콴텍에서 로보어드바이저 서비스를 만들었습니다.

AI 대화 기능은 진행 중인 거래 하나로 범위를 막고 시작했습니다. 사용자가 AI에게 무엇을 물을지 몰랐기 때문입니다. 베타에서 오간 대화를 읽어보니, 사람들이 맡기고 싶어 한 일은 흩어진 기록을 대신 읽는 것과 다음에 할 일을 짚어주는 것이었습니다. 그 요구가 거래 안에만 있지 않아서, 잠재 고객과 회사와 고객까지 범위를 넓혔습니다.

고객사마다 워크스페이스가 중복으로 만들어지던 문제는 세팅을 돕다 발견했습니다. 팀원을 초대하는 길이 있다는 걸 아무도 모르고 있었습니다. 안내 문구를 고치는 대신 가입 단계로 돌아가 초대를 그 안에 넣었고, 중복이 21%에서 4.4%로 줄었습니다.

## 해온 일

**AI 어시스턴트 진입 지점 재설계.** 고객과 거래 정보가 놓인 화면에서 AI를 열어본 사람이 다시 돌아온다는 것을 인터뷰 40건과 대화 기록 1,500건에서 확인하고, AI를 부르는 자리를 그 맥락으로 옮겼습니다. 사용량 8.5% → 17.2%.

**AI 미팅 녹음.** POC부터 출시, 출시 후 개선까지 맡았습니다. 요약을 노트로 저장하는 기능과 템플릿이 메뉴 안에 숨어 아무도 찾지 못하고 있어서, 화면 위로 꺼냈습니다. 노트 저장률 7.9% → 27.8%, 첫 사용 후 이탈률 47.7% → 38.7%.

**삭제 정책 리뉴얼.** 실수로 지웠다는 불만과 지우는 게 번거롭다는 불만을 같이 받고 있었습니다. 데이터 중요도를 5단계로 나눠 삭제 절차의 난이도를 다르게 뒀습니다. 복구 요청 12건 → 1건.

**투자 성향 분석 퍼널.** 성향 분석 문항을 쉬운 말로 다시 쓰고, 홈 화면은 클릭 데이터를 보고 순서를 다시 잡았습니다. 성향 분석 전환율 +41.2%p, 가입까지 걸리는 시간 50% 단축.
