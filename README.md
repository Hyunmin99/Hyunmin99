# 권현민

프로덕트 디자이너입니다. 규칙과 예외가 많은 B2B 제품에서 문제를 정의하고, 사람들이 실제로 쓰는 화면으로 만듭니다.

지금은 세일즈맵에서 AI CRM을 만들고 있습니다. AI 기능을 설계할 때는 결과를 그럴듯하게 보여주는 일보다, 사용자가 어디까지 믿어도 되는지를 정하는 일이 먼저라고 생각합니다. 그 전에는 티맥스가이아에서 공공기관과 기업이 쓰는 문서 편집 SaaS를, 에이아이콴텍에서 로보어드바이저 서비스를 만들었습니다.

숫자를 근거로 쓰되, 그 숫자가 어떤 기준으로 만들어졌는지부터 확인합니다. 인터뷰에서 들은 말은 실제 사용 데이터와 다시 맞춰 봅니다. 정상 화면만 넘기지 않고 권한, 빈 상태, 실패, 복구까지 함께 정리해 넘깁니다.

## 최근에 한 일

**AI 어시스턴트 진입 맥락 재설계.** 고객과 거래 정보가 있는 화면에서 AI를 열었을 때 다시 찾는 비율이 높다는 것을 확인하고, 호출 지점과 응답 범위를 다시 설계했습니다. 사용량 8.5% → 17.2%.

**AI 미팅 녹음.** POC부터 출시, 출시 후 개선까지 맡았습니다. 메뉴 안에 숨어 있던 노트 저장과 템플릿 기능을 화면 위로 꺼냈습니다. 노트 저장률 7.9% → 27.8%, 첫 사용 후 이탈률 47.7% → 38.7%.

**삭제 정책 리뉴얼.** 데이터 중요도에 따라 삭제 절차의 난이도를 다르게 설계해, 삭제 실수와 번거로운 절차라는 상반된 불만을 같이 해결했습니다. 복구 요청 12건 → 1건.

**투자 성향 분석 퍼널.** 성향 분석 문항과 홈 화면의 우선순위를 다시 잡았습니다. 성향 분석 전환율 +41.2%p, 가입까지 걸리는 시간 50% 단축.
